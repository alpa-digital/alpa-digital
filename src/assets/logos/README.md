# Logos de clientes a color

Coloca aquí el logo oficial a color de cada empresa con el nombre exacto de su `slug`
(ver `src/data/clients.ts`). Formatos admitidos: `.svg` (preferido), `.png`, `.webp`, `.jpg`.

| Empresa          | Archivo esperado   |
| ---------------- | ------------------ |
| AC Marca         | `ac-marca.svg`     |
| CAF              | `caf.svg`          |
| Cepsa            | `cepsa.svg`        |
| Cirsa            | `cirsa.svg`        |
| Deoleo           | `deoleo.svg`       |
| Esteve           | `esteve.svg`       |
| Fluidra          | `fluidra.svg`      |
| Goodyear         | `goodyear.svg`     |
| Logista          | `logista.svg`      |
| Grup Peralada    | `peralada.svg`     |
| Telefónica Tech  | `telefonica.svg`   |
| Vectalia         | `vectalia.svg`     |

Recomendaciones: fondo transparente, versión horizontal, sin márgenes grandes.
Mientras falte el archivo, la web muestra la versión monocroma heredada o el nombre en texto.
